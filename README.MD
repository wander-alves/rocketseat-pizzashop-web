# Rocketseat PizzaShop Web

## Sobre
Esse projeto está sendo desenvolvido durante a trilha de React de 2022 da [Rocketseat](https://rocketseat.com.br), onde desenvolvemos uma aplicação para gerenciamento de restaurantes completa, com login, gerenciamento de pedidos e métricas customizadas para acompanhamento dos restaurantes e evolução das vendas.
...

## Tecnologias
Esse projeto foi desenvolvido com café, amor e também com seguintes tecnologias: 

- React.js
- Vite.js
- React Router DOM
- Zod.js
- Tailwind
- ShadCN
...
